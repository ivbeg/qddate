## Related libraries

If qddate is the wrong tool for a job, the usual alternatives are
[dateparser](https://github.com/scrapinghub/dateparser) and
[python-dateutil](https://github.com/dateutil/dateutil). See
[when to use](/getting-started/when-to-use).

The original parser dates to 2008 and evolved from regular expressions into
pyparsing. Thanks to the ScrapingHub dateparser team for the motivation to
clean up the public release.
